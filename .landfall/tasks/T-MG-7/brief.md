## Findings (run `landfall findings show <ID>` for the full text; reproductions in scratchpad/reviews/core/core.test.ts, core/exmember.test.ts and the codex text)
1. B-MG-1 (blocking) + B-MG-29: listNotifications and unread notification counts ignore CURRENT access: after removal from a private channel the actor still sees excerpts. Fix: filter by canRead at read time (join conversations/memberships), also for the count. Test: mention bob in a private channel, remove bob -> listNotifications(bob) has no such row and the count excludes it; a public-channel mention stays.
2. B-MG-6 (blocking) + B-MG-53: whoIsTyping and GET /api/presence expose typing locations (typingIn 'c:<id>') and session details for conversations the viewer cannot read. Fix: for each viewer, drop or null typingIn (and the per-session "doing" only if it names a private conversation - keep "doing" free text) unless canRead(viewer, that conversation); sessions' cwd/host/ids: return them only to the owner and to human admins. Test: alice types in a private channel bob is not in -> bob's presence shows no typing location for it; alice sees her own.
3. B-MG-7 (blocking) + B-MG-48: postMessage (src/core/messages.ts ~224), file upload and lease routes accept a client sessionId without checking it belongs to the actor. Fix: verify ownership (sessions.actor_id === actor) or ignore the sessionId (drop it, do not fail the post). Test: bob posts with alice's sessionId -> the message is stored without that sessionId and alice's typing bubble is NOT cleared.
4. B-MG-9 (blocking) + B-MG-27: src/store/db.ts ~109-122: callbacks registered with onCommitted inside a savepoint that is rolled back still fire after the outer COMMIT. Fix: record the queue length at savepoint entry and truncate to it on rollback of that savepoint. Test: outer tx catches an inner tx that posts and throws, outer commits -> the subscriber received nothing from the inner part, and the outer callbacks still fire.
5. B-MG-23 (blocking): editMessage/deleteMessage (messages.ts ~291) check only authorship: an ex-member of a private channel can still edit/delete and the edit notifies current members. Fix: require canRead (current membership) for edit and delete, and not archived for edit. Test: remove bob from the private channel -> editMessage by bob throws forbidden, no event, no notification.
6. B-MG-24 (blocking): src/core/wiki.ts ~206 assertNoClobber ignores force when baseRevision is also present -> an agent following the 409 hint ("force=true") loops. Fix: check force first. Test: stale baseRevision + force=true -> saved, new revision.
7. B-MG-25: db.ts ~15: set busy_timeout BEFORE `PRAGMA journal_mode=WAL` and retry the WAL pragma on SQLITE_BUSY. Test: open the same NEW file from several processes at once (child_process, 6 processes) -> all succeed.
8. B-MG-26: db.ts ~36: refuse to open a DB whose user_version is greater than the schema version this binary knows, with an actionable error ("database was created by a newer AgentTalks (vX); upgrade the binary"). Test.
9. B-MG-28: notifications sweep runs two full-table DELETEs on every notify(). Fix: sweep at most once per 60 s per process (module-level timestamp) and/or add an index via a new migration. Test: two notify() calls within a second run the sweep once (spy or counter).
10. B-MG-30: markRead accepts any messageId -> clamp to the conversation's last message id. Test: markRead(conv, 10^6) then a new message is unread.
11. B-MG-31: dedup key actor:clientMsgId lacks the conversation -> include conversationId (new key format; keep old rows valid). Test: same clientMsgId in two channels -> two messages.
12. B-MG-32: unreadFor/digestFor count all unread rows -> cap the counted rows (e.g. count up to 1000, report "999+" semantics as a number cap) using a LIMIT subquery. Test: counts still exact under the cap; timing on 300k rows under 50 ms (state the number).
13. B-MG-47: POST /api/wiki/:slug/files decodes X-File-Name with raw decodeURIComponent -> a bad %-sequence is a 500. Fix: reuse the files route's safe decoder (400). Test: 'bad%zz.txt' -> 400.
