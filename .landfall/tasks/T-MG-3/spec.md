## Amendment 1 (2026-11-04, D-MG-18): GitHub's design system (Primer) as the visual layer
Owner: "zrob jeszcze tak aby UI korzystalo z DS GitHuba". Interaction model stays Slack's (all slices); the VISUAL layer becomes Primer: @primer/primitives 11.10.0 tokens (CSS custom properties for color modes light/dark incl. data-color-mode/data-light-theme/data-dark-theme, typography, spacing, borders, shadows), @primer/css 22.3.3 component styles where they fit (Button, TextInput/FormControl, Label, Counter, Avatar/AvatarStack, Overlay/Dialog, ActionList/ActionMenu, Tooltip, Flash, Box, SelectMenu, Timeline-style thread lines), @primer/octicons 19.42.0 SVG icons replacing the in-house icons.js set. All MIT; vendored as static files under src/http/ui/vendor/primer/ (LICENSE + VERSIONS.md), served through the ui.ts whitelist; no npm runtime dependency, no build step.
New slice S0b (after S0, before S1): adopt Primer tokens and the theme switch (light/dark/auto following the OS), map every app.css color/space/radius/font to a Primer token (no raw hex left in app.css except inside the vendored files), swap icons to Octicons, restyle buttons/inputs/labels/avatars/menus/dialogs/tooltips with Primer classes. Acceptance: (1) grep app.css for /#[0-9a-f]{3,8}\b/ outside comments -> 0; (2) both color modes render with sufficient contrast (WCAG AA on text, checked live); (3) every icon comes from Octicons; (4) the vendored files carry their MIT LICENSE and pinned versions; (5) no GitHub logo, name or trademark in UI copy or assets.
## Amendment 2 (2026-11-04): screenshot verification by an independent UX/UI agent closes T-MG-3
Owner: "jak skonczysz, zrob weryfikacje screenshotowa i przejslij to do review do UX/UI agenta niech sam oceni czy to w ogole jest intuicyjne, zrozumiale, czy nie ma bledow, czy wiadomo w co kliknac i co to zrobi, czy jest przyjemne dla oka, czy stosuje DS etc. A potem zakoncz ta sesje po wszystkich poprawkach".
After the implementation slices: capture screenshots of every main screen and state (login, empty and busy channel, thread open, composer with mention/emoji/command popovers, DM, people/profile, activity, search, wiki, admin, error and offline states; light and dark; 1440 px and 390 px; EN and PL) from a seeded local instance; a fresh landfall:reviewer on fable reviews them (plus the live UI) for: intuitiveness, clarity of labels, obvious affordances (what to click and what it does), visual errors, aesthetic quality, Primer DS adherence, Slack interaction parity, accessibility. Every finding is fixed in a fix round and re-verified with new screenshots; then deploy and end the session.

The brand-copy guard of section 5 is amended accordingly: the Slack guard stays as written; for GitHub, Primer tokens/components/Octicons are allowed (published for reuse under MIT), GitHub's logo, name and marks are not.
