## S0b (Primer)
1. Vendor (no npm runtime dependency, no build): download with `npm pack @primer/primitives@11.10.0 @primer/css@22.3.3 @primer/octicons@19.42.0` into a scratch directory outside the worktree, extract, and copy ONLY what the UI needs into src/http/ui/vendor/primer/: the primitives CSS for color modes light and dark (+ their -high-contrast variants only if small), typography, size/spacing, border, shadow; the Primer CSS component styles the UI uses (Button, form controls, Label/Counter, Avatar, Overlay/Dialog, ActionList/ActionMenu, Tooltip, Flash, Box/base utilities) - prefer the smallest built files; and the Octicons SVGs the UI uses (16 px set) as one sprite or individual files. Add LICENSE files (MIT) and VERSIONS.md (package, version, file list, sha256). Serve them through the whitelist in src/http/ui.ts (extend it to the vendor path with an explicit file list or directory allowlist; content types for .css/.svg; same caching/stamp rules as other assets; nothing else under vendor/ servable).
2. Theme: html gets data-color-mode="auto" data-light-theme="light" data-dark-theme="dark" (Primer convention); a theme switch (Auto / Light / Dark) in the user menu, persisted in localStorage; follows the OS in Auto.
3. app.css: map every color, font, font size, line height, spacing, radius, border and shadow to Primer CSS variables (--fgColor-*, --bgColor-*, --borderColor-*, --base-size-*, --borderRadius-*, --shadow-*, font stacks); no raw hex/rgb/hsl values remain outside comments (acceptance: grep /#[0-9a-fA-F]{3,8}\b|rgb\(|hsl\(/ on app.css outside comments -> 0, a test enforces it). Keep the existing layout; S1-S7 change layout later.
4. Icons: replace the in-house icons.js set with Octicons (same exported function names so callers do not change, or update all callers), with aria-hidden on decorative icons and labels on icon-only buttons.
5. Components: buttons, inputs, labels/badges/counters, avatars, menus, dialogs/confirm modals, tooltips, toasts/flash use Primer classes or Primer-token-styled equivalents.
6. Brand guard: no GitHub logo, name or marks anywhere in UI copy or assets; no Slack name/logo/colors.
Acceptance for S0b: (1) the hex/rgb grep test passes; (2) light and dark both render with WCAG AA text contrast on the main surfaces (measure 5 pairs with the browser via javascript_tool getComputedStyle and report the ratios); (3) every icon comes from Octicons; (4) vendored files have LICENSE + VERSIONS.md with sha256; (5) zero console errors; existing UI tests green; screenshots of #general in light and dark at 1440 px described in the report.
